# Homebrew Tap for cmux

> [!NOTE]
> `cmux` has been moved to the [official Homebrew cask repository](https://formulae.brew.sh/cask/cmux).

This is the original Homebrew tap for [cmux](https://github.com/manaflow-ai/cmux), a Ghostty-based macOS terminal with vertical tabs for AI coding agents.

## Migration

To Migrate from this Tap

```bash
brew uninstall --cask cmux
brew untap manaflow-ai/cmux
brew update
brew install --cask cmux
```

## Installation (Preferred - official cask method)

```bash
brew install --cask cmux
```

## Install this tap (Deprecated)

```bash
brew tap manaflow-ai/cmux
brew install --cask cmux
```

## Updating

```bash
brew upgrade --cask cmux
```

## Uninstalling

```bash
brew uninstall --cask cmux
brew untap manaflow-ai/cmux
```
